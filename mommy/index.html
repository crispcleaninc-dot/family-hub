Mommy Is Human Too

Read-along books · coloring book · moving characters · story makers · Picture Studio

You're offline. The books and pictures are kept in Google Drive, so the app needs internet. It opens as soon as you're connected.

iPhone / iPad: in Safari tap Share → Add to Home Screen → Add.
Android: in Chrome tap ⋮ → Install app (or Add to Home screen).
Windows / Mac: in Chrome or Edge click the install icon at the right end of the address bar.

After installing, open it from the new “Mommy Is Human” icon. It goes straight to the books.
